Nova avaliação Histórico API

Uma interface de demonstração, não um produto. Verifica um evento descrito em relação às condições filiadas de um produto de seguro automotivo registrado na SUSEP — não decide se um sinistro real seria pago. Toda execução para em um checkpoint humano.
